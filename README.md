Entry for [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0)
on make.fun: coin one new English word and define it in a single clear line.

## The entry

> Roomlapse (n.): the blank moment when you cross a doorway and forget why you entered the room.

## Run

```sh
python3 -P -s main.py
```

Writes the entry text (94 characters) to `/output/entry.txt`. Python 3
standard library only, deterministic, no network.
